# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a text-based Hangman game in Python that uses strings, loops, and user input to let a player guess a hidden word before they run out of attempts.

## 📝 Tasks

### 🛠️ Build the Word and Guessing Logic

#### Description
Create a Python program that chooses a secret word, shows the current guessed letters, and accepts player input for each turn.

#### Requirements
Completed program should:

- Store a list of words and randomly choose one for each game
- Display the hidden word as underscores or blanks for unguessed letters
- Accept single-letter guesses from the player
- Reveal correctly guessed letters in the correct positions
- Keep track of guesses remaining and previously guessed letters

### 🛠️ Add the Game End Conditions and Feedback

#### Description
Finish the game so it clearly communicates the outcome and handles both win and loss scenarios.

#### Requirements
Completed program should:

- End the game when the player guesses the full word
- End the game when the player runs out of allowed attempts
- Display a clear win or lose message at the end
- Show the secret word when the game ends
- Prevent repeated guesses and update the display after each turn
